# 海康监控驱动开发指南

## 1. 项目概述

该文档主要介绍自定义开发驱动的开发流程，包含驱动配置读取、修改和接口元数据查询。

关键目录如下：

| 路径 | 说明 |
| --- | --- |
| `src/main/java/com/neucity/hikvision_drive/web/ConfigController.java` | 驱动配置读取、修改和接口元数据查询 |
| `src/main/java/com/neucity/hikvision_drive/web/DriveController.java` | 公共设备/事件接口和监控业务接口 |
| `src/main/resources/config.json` | 驱动运行配置，包含登录配置 `login` 和通用配置 `configs` |
| `src/main/resources/api.json` | 驱动接口注册/展示元数据 |
| `docker/Dockerfile` | Docker 镜像构建文件 |
| `docker/docker-compose.yml` | Docker Compose 部署文件 |

## 2. Docker 部署要求

本驱动必须使用 Docker 部署，不建议直接在宿主机通过 `java -jar` 裸跑。

宿主机端口必须通过 `HOST_MACHINE_PORT` 变量指定。`docker-compose.yml` 中端口映射要求如下：

```yaml
ports:
  - "HOST_MACHINE_PORT:20001"
```

服务启动后访问地址格式：

```text
http://宿主机IP:HOST_MACHINE_PORT/api/v1/接口路径
```

例如：

```text
http://127.0.0.1:20001/api/v1/config
```

## 3. 配置文件说明

### 3.1 config.json

`config.json` 是驱动运行配置文件，默认位于 `src/main/resources/config.json`。运行时 `ConfigLoader` 会按以下优先级读取：

1. JVM 参数 `-Dconfig.path`
2. 环境变量 `CONFIG_PATH`
3. 当前工作目录下的 `config.json`
4. `src/main/resources/config.json`
5. jar 包内 classpath 的 `config.json`

配置结构示例：

```json
{
  "login": {
    "ip": "172.11.10.31",
    "port": 443,
    "host": "https://172.11.19.121",
    "key": "appKey",
    "secret": "appSecret"
  },
  "configs": [
    {
      "key": "configPath",
      "label": "配置文件路径",
      "value": "/etc/obos/drivers/hikvision/config.yaml"
    }
  ]
}
```

`login` 对象用于配置平台连接信息：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `host` | string | 否 | 平台完整访问地址，支持 `http://` 或 `https://`，可包含端口和上下文路径。配置后优先使用该字段 |
| `ip` | string | `host` 为空时必填 | 平台 IP 地址；当 `host` 为空时，驱动会根据 `ip` 和 `port` 拼接基础地址 |
| `port` | int | 否 | 平台端口，默认 `8000`；当 `host` 未带端口时会自动追加 |
| `key` | string | 是 | 接口认证 AppKey，用于 `x-ca-key` 签名头 |
| `secret` | string | 是 |接口认证 Secret，用于 HMAC-SHA256 签名 |

登录信息可通过注册表/驱动管理平台调用 `ConfigController` 修改，本质上是更新 `config.json` 的 `login` 对象。若部署时通过 `CONFIG_PATH` 挂载外部配置文件，修改会写入该外部配置文件；否则会写入当前工作目录或项目资源目录中可写的 `config.json`。

## 4. ConfigController 接口

控制器基础路径：`/api/v1/config`

统一返回结构：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | boolean | 是否成功 |
| `message` | string | 返回信息 |
| `errorCode` | int | 错误码，成功时通常为 `null` |
| `data` | object/array | 返回数据 |

### 4.1 获取配置

```text
GET /api/v1/config
```

返回 `config.json` 完整内容。

### 4.2 修改配置

```text
PUT /api/v1/config
Content-Type: application/json
```

请求体为完整 `config.json` 内容。修改登录信息时，需要保留 `login` 对象结构。

### 4.3 获取接口元数据

```text
GET /api/v1/config/api
```

返回 `api.json` 数组内容，供注册表/驱动管理平台展示当前驱动支持的接口。

#### 查询监控点列表 v2

```text
POST /api/v1/drive/device/search
```

该接口用于查询监控点列表，当前实现调用海康 `/artemis/api/resource/v2/camera/search`。

请求参数：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `name` | string | 否 | - | 名称，模糊搜索字段 |
| `pageNo` | int | 否 | `1` | 当前页码 |
| `pageSize` | int | 否 | `1000` | 每页数量 |

请求示例：

```json
{
  "name": "大厅",
  "pageNo": 1,
  "pageSize": 100
}
```

返回 `data` 为设备列表：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 监控点名称，当前由下游 `name` 映射 |
| `address` | string | 区域名称/安装位置，当前由下游 `regionName` 映射 |
| `ip` | string | 设备 IP，当前实现未赋值 |
| `port` | int | 设备端口，当前实现未赋值 |
| `serialNumber` | string | 监控点唯一标识，当前由下游 `indexCode` 映射 |
| `extend` | string | 原始监控点对象 JSON 字符串 |

返回示例：

```json
{
  "success": true,
  "message": "查询监控点列表v2",
  "errorCode": null,
  "data": [
    {
      "name": "大厅摄像机",
      "address": "一楼大厅",
      "ip": null,
      "port": null,
      "serialNumber": "camera-001",
      "extend": "{\"name\":\"大厅摄像机\",\"regionName\":\"一楼大厅\",\"indexCode\":\"camera-001\"}"
    }
  ]
}
```

#### 增量获取报警输出数据


该接口用于按时间范围增量获取报警输出数据，当前实现调用海康 `/artemis/api/resource/v1/alarmOut/timeRange`。

请求参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `startTime` | string | 否 | 开始时间，格式遵循海康接口要求 |
| `endTime` | string | 否 | 结束时间，格式遵循海康接口要求 |
| `pageNo` | int | 否 | 当前页码 |
| `pageSize` | int | 否 | 每页数量 |

请求示例：

```json
{
  "startTime": "2026-06-29T00:00:00.000+08:00",
  "endTime": "2026-06-29T23:59:59.000+08:00",
  "pageNo": 1,
  "pageSize": 100
}
```

返回 `data` 为事件列表。当前代码中已完成下游调用和成功校验，但事件对象映射逻辑暂未填充，因此成功时可能返回空数组。

| 字段          | 类型 | 说明 |
|-------------| --- | --- |
| `indexCode` | string | 事件关联对象编号，当前实现未赋值 |
| `eventId`   | string | 事件 ID，当前实现未赋值 |
| `eventName` | string | 事件名称，当前实现未赋值 |
| `eventTime` | string | 事件时间，当前实现未赋值 |
| `level`     | string | 事件等级，当前实现未赋值 |
| `extend`    | string | 原始事件对象 JSON 字符串，当前实现未赋值 |

#### 根据监控点编号进行云台操作

```text
POST /api/v1/drive/cameras/ptzs/controlling
```

该接口用于根据监控点编号控制云台，当前实现调用海康 `/artemis/api/video/v1/ptzs/controlling`。

请求参数：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `cameraIndexCode` | string | 是 | - | 监控点唯一标识，可通过分页获取监控点资源接口返回的 `cameraIndexCode` 或公共设备查询返回的 `serialNumber` 获取 |
| `action` | int | 是 | - | 操作动作：`0` 开始，`1` 停止。`GOTO_PRESET` 命令下填任意值均可转到预置点，建议填 `0` |
| `command` | string | 是 | - | 云台命令，见下方命令列表 |
| `speed` | int | 否 | `50` | 云台速度，取值范围 `1-100` |
| `presetIndex` | int | 否 | - | 预置点编号，通常在 `300` 以内；当 `command` 为 `GOTO_PRESET` 时不可为空 |

常用 `command` 取值：

| 值 | 说明 |
| --- | --- |
| `LEFT` | 左转 |
| `RIGHT` | 右转 |
| `UP` | 上转 |
| `DOWN` | 下转 |
| `ZOOM_IN` | 焦距变大 |
| `ZOOM_OUT` | 焦距变小 |
| `LEFT_UP` | 左上 |
| `LEFT_DOWN` | 左下 |
| `RIGHT_UP` | 右上 |
| `RIGHT_DOWN` | 右下 |
| `FOCUS_NEAR` | 焦点前移 |
| `FOCUS_FAR` | 焦点后移 |
| `IRIS_ENLARGE` | 光圈扩大 |
| `IRIS_REDUCE` | 光圈缩小 |
| `WIPER_SWITCH` | 接通雨刷开关 |
| `START_RECORD_TRACK` | 开始记录路线 |
| `STOP_RECORD_TRACK` | 停止记录路线 |
| `START_TRACK` | 开始路线 |
| `STOP_TRACK` | 停止路线 |
| `GOTO_PRESET` | 转到预置点，需传 `presetIndex` |

请求示例：

```json
{
  "cameraIndexCode": "camera-001",
  "action": 0,
  "command": "LEFT",
  "speed": 50
}
```

转到预置点示例：

```json
{
  "cameraIndexCode": "camera-001",
  "action": 0,
  "command": "GOTO_PRESET",
  "speed": 50,
  "presetIndex": 1
}
```

返回说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | boolean | 操作是否成功。海康返回 `code = 0` 时为 `true` |
| `message` | string | 成功返回 `操作成功`，失败返回 `操作失败：` 加海康错误信息 |
| `errorCode` | int | 失败时为 `500`，成功时为 `null` |
| `data` | string | 成功时为空字符串 |

返回示例：

```json
{
  "success": true,
  "message": "操作成功",
  "errorCode": null,
  "data": ""
}
```

#### 获取监控点预览取流URLv2

```text
POST /api/v1/drive/cameras/previewURLs
```

该接口用于获取监控点实时预览取流 URL，当前实现调用海康 `/artemis/api/video/v2/cameras/previewURLs`。

请求参数：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `cameraIndexCode` | string | 是 | - | 监控点唯一标识，可通过分页获取监控点资源接口返回的 `cameraIndexCode` 或公共设备查询返回的 `serialNumber` 获取 |
| `streamType` | int | 否 | `0` | 码流类型，常见取值：`0` 主码流，`1` 子码流 |
| `protocol` | string | 否 | - | 取流协议，按海康接口支持值传入，例如 `rtsp`、`rtmp`、`hls`、`ws` 等 |
| `transmode` | int | 否 | - | 传输模式，按海康接口要求传入 |
| `expand` | string | 否 | - | 扩展参数，JSON 字符串 |
| `streamform` | string | 否 | - | 码流封装格式，按海康接口支持值传入 |

请求示例：

```json
{
  "cameraIndexCode": "camera-001",
  "streamType": 0,
  "protocol": "rtsp",
  "transmode": 1,
  "expand": "streamform=rtp",
  "streamform": "rtp"
}
```

返回 `data` 为取流 URL 对象：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `url` | string | 监控点预览取流地址 |

返回示例：

```json
{
  "success": true,
  "message": "获取监控点预览取流URLv2",
  "errorCode": null,
  "data": {
    "url": "rtsp://example.com/openUrl/..."
  }
}
```

| 文件 | 说明 |

| `Dockerfile` | 镜像构建文件 |
| `hikvision-monitor-drive.jar` | 已构建完成的 Spring Boot 启动 jar |

zip 内容应为：

```text
hikvision-monitor-drive.zip
├── docker-compose.yml
├── Dockerfile
└── hikvision-monitor-drive.jar
```
