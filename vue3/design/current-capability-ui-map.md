# 现有系统功能与 UI 映射

本文件只记录当前源码已经具备或已经暴露入口的能力，作为 UI 重设计边界。

## 首页

当前状态：品牌 Logo 与应用 Dock。

允许优化：使用已有接口聚合为工作台，不增加后端能力。

- 设备分类概览：在线、异常、离线、总数。
- 事件概览：高、中、低级事件及处理状态。
- 系统资源：CPU、内存、存储、网络。
- 环境检测：风速、PM2.5、PM10、温度、湿度、噪声。
- 最近设备操作：复用设备操作日志。
- 8 个现有应用入口。

## 注册表

- 按分类浏览驱动树。
- 驱动信息。
- 驱动登录配置信息与编辑。
- 驱动下设备列表。
- 驱动服务/API 列表。
- 服务详情、请求参数与返回信息。

## 资源管理器

- 系统资源监控：CPU、内存、存储、网络。
- 环境检测：风速、PM2.5、PM10、温度、湿度、噪声。
- 5 秒自动刷新。

## 数据中心

- 按设备分类查看数据对象。
- 按厂商、名称筛选。
- 展示设备名称、序列号、厂商、位置和在线状态。
- 分页。
- “历史数据”目前为开发中，不在设计中展示成可用趋势功能。

## 设备中心

- 按设备分类浏览：电梯、门禁、监控、能源、照明、环境监测等动态分类。
- 分类设备概览：在线、异常、离线、总数。
- 按厂商、名称筛选设备。
- 设备列表、设备状态、开关状态。
- 门禁控制：常开、门闭、门开、常闭。
- 照明：单设备开关；后端存在全部照明开关接口。
- 监控：预览、云台、抓拍、录制、声音、刷新、全屏。
- 人脸识别布控：选择关联门禁，开启和关闭。
- 设备操作日志与详情。

## 事件中枢

- 事件总览：高、中、低级事件统计。
- 事件列表：级别、时间、来源、处理状态。
- 按级别、处理状态和关键字筛选。
- 事件详情与扩展信息。
- 事件规则：列表、筛选、新增、启用、禁用、详情。
- “事件跟进”和事件分发当前为开发中，不作为完成能力设计。

## 空间对象管理

- 当前只有 Dock 入口，点击提示开发中。
- 新设计中保留入口并明确“建设中”，不增加地图、楼层或数字孪生功能。

## 驱动管理

- 驱动总览与筛选。
- 上传驱动及 Logo，展示上传进度。
- 安装、卸载、触发更新。
- 驱动开发指南查看与下载。

## 桌面与窗口边界

- 当前只允许一个活动应用。
- 当前最小化等同于关闭。
- 可在纯前端范围完善真正的最小化、恢复和运行状态，不依赖后端。
- Dock 的模块名称与顺序保持不变。

## 不允许在效果图中伪造的能力

- 建筑三维模型或楼层图。
- 空间实时定位与影响范围。
- 建筑智能体推理、置信度和自动建议。
- 未实现的历史曲线与数据血缘。
- 未实现的事件自动分发和处置闭环。
- 后端没有返回的控制回读阶段。
